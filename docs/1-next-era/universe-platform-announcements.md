## One release story across the stack

The collage groups announcements that can look like separate features: models and agents, repetitive workflows, memory, security and pull request review. They are connected by the system around the work. Copilot helps create and coordinate changes; review and security features help assess them; the Git platform is being redesigned to handle more concurrent activity.

That is why the announcements are easier to understand as a platform evolution than as a checklist of new buttons. Each capability addresses a different point in the path from an idea or signal to work that is reviewed and shipped. The individual pages in this chapter explain the parts and link to their release details.

Release stages differ across the collage. Some capabilities are generally available and others are in preview, so check the current documentation before planning a rollout.
