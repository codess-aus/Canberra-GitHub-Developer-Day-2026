## Keep the task moving between tools

The image shows one cloud agent session moving through a working day: start it from GitHub Mobile, steer it from an editor, answer a question in team chat and review the resulting pull request in the Copilot app. The point is continuity: the developer can change surfaces without losing the task's conversation and progress.

GitHub's connected Copilot cloud experience supports following and steering cloud sessions across supported clients. Cloud sandboxes keep agent work in an environment hosted by GitHub; local sandboxes run on the developer's machine and can restrict filesystem, network and credential access. These approaches suit different needs, so consider the data and tools an agent needs before choosing where it runs.

The clients and availability can change as the feature evolves. Check the current documentation and organisational policies before relying on cross-client session continuity.
