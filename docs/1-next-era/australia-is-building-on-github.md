## A local view of a global shift

The figures on this slide put the keynote's global story in an Australian context. The GitHub Innovation Graph reports more than 2.57 million developers in Australia, 5.26 million code uploads during the June 2026 quarter, and more than 4.8 million repositories owned by Australian developers and organisations.

The three measures describe different things: developer accounts, code uploads and repositories. Together they show both the size of the community and the activity it produces. The reported year-on-year increases are 30% for developers, 111% for uploads and 19% for repositories.

For teams in Australia, this growth means more opportunities to reuse open source and collaborate across borders. It also brings the same practical challenge raised elsewhere in the keynote: review, security and governance need to keep pace with the amount of work being created.
