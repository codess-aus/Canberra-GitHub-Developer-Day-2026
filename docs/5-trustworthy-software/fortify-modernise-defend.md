    Fortify closes existing gaps. Modernise replaces or upgrades fragile applications. Defend detects and responds to threats in running systems.

## Three tracks, not three sequential projects

An organisation can fix vulnerable code and identities now, modernise systems that are difficult to maintain, and defend workloads already in production at the same time. The tracks reinforce each other: modernisation can reduce future patching work, while detection and response protect the systems that cannot be changed immediately.

GitHub Code Security contributes findings and remediation workflows; Copilot modernization can assist with .NET and Java upgrades; and Microsoft security services supply posture and operational context. Each remains subject to the organisation's architecture and review requirements.
