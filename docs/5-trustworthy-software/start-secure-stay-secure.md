    Start secure. Stay secure. Secure by default.

## A practical starting point

**Start secure** by identifying important repositories, scanning existing code and dependencies, and assigning owners to the findings. **Stay secure** by placing checks at push, pull request, package installation and release. **Be secure by default** by applying the baseline to new repositories and defining permissions and review for agents.

A useful first exercise is a 30-day pilot across a manageable set of repositories, such as 20 selected for risk and ownership. Agree who will enable the controls, triage findings and review fixes, then measure coverage and remediation progress. Adjust the number to the team's capacity and available licences rather than treating it as a product limit.
