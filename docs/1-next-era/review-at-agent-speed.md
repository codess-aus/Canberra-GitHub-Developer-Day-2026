## Verification is part of delivery

More agent-generated changes increase the importance of reviewing what is ready to merge. The capabilities on this slide address different parts of that process:

- **Copilot code review Max** uses several review agents for a deeper analysis of higher-risk changes. It is in public preview.
- **Copilot approvals** can count toward required pull request approvals when enabled.
- **Agent Merge** watches a pull request and can help resolve blockers such as failing workflows or merge conflicts.
- **Stacked pull requests** split a large change into smaller, linked reviews.
- **GitHub Code Quality** surfaces findings that teams can address before merging.

These features can help teams scale their checks, but they do not replace ownership of the change. Decide which repositories can use them, who remains responsible for approval and how the team will respond to a finding.
