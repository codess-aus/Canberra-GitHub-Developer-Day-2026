## Four patterns to watch

The slide looks beyond individual product announcements to four ways development practices may change:

- **Spec-driven development** starts with a clear specification, plan and tasks before agents implement code. GitHub's Spec Kit is an open-source toolkit for this approach.
- **Continuous AI** applies agent reasoning to recurring repository work, alongside the automation already provided by CI.
- **Systems that learn** use memory, feedback and automation outcomes to improve the context and instructions available to later work.
- **Humans and agents together** keep people responsible for direction and decisions while agents implement and verify work.

These patterns reinforce one another. Clear intent gives agents better boundaries; continuous checks help assess the output; and memory can carry useful lessons forward. The human role is not removed from the loop: it becomes more focused on deciding what should be built and what evidence is sufficient to ship it.
