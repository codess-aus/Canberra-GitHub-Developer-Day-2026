**Session 01, 09:00 to 09:45**

**Keynote** by Anthony Borton, Director, Field Services APAC East, GitHub.

The keynote draws on the announcements from GitHub Universe 2026, held on 28 October 2026, and follows a simple arc. AI is speeding up software development, which creates more activity and more complexity. GitHub's answer is to bring AI, collaboration and security into the places where teams already work, then give organisations the controls to decide what moves forward.

This chapter walks that arc slide by slide. Each page explains what the slide says, adds detail from GitHub Docs, the GitHub Blog and the Universe changelog, and points out what matters for a team working under government rules.

## Key terms

- **GitHub Copilot app:** a desktop application for agent-driven development, where you direct agents across parallel work from one place.
- **Copilot Projects:** give Copilot a goal and let it coordinate work across repositories, sessions and recurring tasks.
- **Copilot Automations:** agent workflows that run on a schedule or in response to repository events, such as issue triage and code review.
- **Copilot Fusion:** a runtime router and orchestrator that chooses which models to use for a task, so developers do not have to.
- **AI Scan:** AI-based security scanning that extends code scanning, including to languages CodeQL does not cover.
- **AI credits:** the metered unit that AI usage is billed in under GitHub's newer Copilot billing models.

## Status check

The slides label each capability with its release stage. Release stages change quickly, so this table compares each label with what GitHub's own pages said when this chapter was written.

| Capability | Label on the slide | What GitHub's pages say |
| --- | --- | --- |
| Copilot access with GitHub Enterprise | GA | The Universe blog says it started on 28 October 2026. |
| Copilot Projects | GA | Copilot Projects is in **public preview**. GitHub Docs and the Universe changelog entry both say so. |
| Copilot Automations | GA | No conflicting status found. |
| Copilot Fusion | GA | The GitHub Changelog says it is generally available. |
| AI Scan for repositories | Public Preview | GitHub Docs says it is in public preview and subject to change. |

Before you plan a pilot around any of these, check the linked Docs page for the current status.

## The route through the keynote

The opening pages frame the shift, then the keynote moves from the Australian developer community into the way GitHub connects work across the delivery lifecycle. The product pages explain Copilot access, Projects, Automations, Fusion and AI Scan; the later slides look at agent workflows, review, security and the platform foundations that support them.

The new slides add a wider view of that story:

- [Australia is building on GitHub](australia-is-building-on-github.md) grounds the global shift in local developer activity.
