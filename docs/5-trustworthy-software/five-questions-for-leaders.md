    Are we patching fast enough? Have we scanned our code? Do we know what is exposed? Is a baseline enforced everywhere? Is security using AI to defend?

## Ask for evidence, not just a tool list

These questions connect executive oversight to operational practice. Patching speed needs an inventory and a way to prioritise; scanning needs coverage of owned code; exposure requires a view of what is actually deployed; and a baseline needs enforcement rather than an optional checklist.

The fifth question asks how AI can support security work, not whether an agent can replace a security team. A useful answer includes what the agent can access, who approves its actions and how the organisation verifies outcomes.
