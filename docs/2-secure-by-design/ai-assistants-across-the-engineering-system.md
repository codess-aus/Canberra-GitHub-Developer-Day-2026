**1ES modernisation outcomes**

## GitHub Copilot

AI assistant for code completion and developer chat.

- **5.5%** increase in PR velocity for the average developer
- **40%** increase in PR velocity, per hour of active coding time

## FirstMate

AI assistant for new hires to accelerate their onboarding journeys.

- **65%** reduction in Time-To-First-PR during a large-scale pilot

## ES Chat

AI assistant for engineering systems providing instant, contextual answers.

- **46.7** minutes saved per task (on average) compared with traditional search methods

## Talk notes

Looking at 1ES modernisation outcomes, let's crunch some numbers.

Using GitHub Copilot, there's a 5.5% increase in PR velocity on average, and a 40% increase in PR velocity per hour of coding time. In other words, the responsiveness.

FirstMate, the AI assistant helping new hires, gives us a 65% reduction in the time it takes to get them started.

ES Chat saves a huge 46.7 minutes on average per task, compared to traditional search methods.
