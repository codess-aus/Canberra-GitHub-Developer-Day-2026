## Work across agents and tools

The slide makes a case for choice. GitHub's Octoverse report found that 61% of Copilot users who chose a model themselves used more than one, and that paid plans used 47 distinct models. The slide adds three examples of that broader ecosystem: partner agents available alongside Copilot, connectors to external services, and an SDK for building with the same agent runtime.

Connectors can provide a managed way to bring tools such as Slack, Figma and Sentry into Copilot workflows. The Copilot SDK makes the agent runtime available to developers building their own applications. The practical benefit is less duplicated setup; the corresponding responsibility is to decide which services, agents and data are allowed by organisational policy.

Availability varies by capability. The Universe announcements mark connectors as a preview, while partner agent access depends on plan and policy. Confirm current eligibility and controls before adopting a connector or agent.
