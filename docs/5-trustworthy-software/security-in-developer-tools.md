## Shorten the distance from finding to fix

Security feedback is most actionable when developers can see the affected code, understand the finding and test a change in the same workflow. The slide shows three surfaces for that collaboration: command-line review, findings in an editor, and a security view in the Copilot app.

An agent can help explain and investigate a finding, but generated fixes still need review and testing. Check what code and tools a session can access, and use the repository's normal approval and scanning process before merging.
