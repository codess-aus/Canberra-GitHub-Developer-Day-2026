    Red team agents assess attack paths; blue team agents support detection and response; green team agents help prioritise and reduce risk. Some capabilities are in preview.

## Different agents, different responsibilities

The slide groups Microsoft Perception capabilities by security outcome. Red team workflows investigate exposure, blue team workflows help with triage and investigation, and green team workflows focus on posture and risk reduction. Some capabilities, including the web application penetration testing and risk reduction agents, are presented as public previews.

Automation does not remove accountability. Scope authorisation and approval steps matter because agents may operate on sensitive data or propose changes to security controls. Before enabling a capability, verify its current permissions, availability, data handling and required human approvals.
