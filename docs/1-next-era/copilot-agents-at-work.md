## From suggestions to delegated work

The slide combines measures from different points in time to show how Copilot use is broadening. GitHub reported more than 140,000 organisations using Copilot in May 2026. Copilot cloud agent use grew 230% year on year, while agent chat grew 85%. By March, Copilot code review had passed 60 million reviews.

The final measure compares pull requests: about 90% of those started by an agent were merged within two weeks, compared with about 86% of other pull requests. These figures describe adoption and outcomes across GitHub; they do not prove that every agent change is correct or ready to merge. Human review and repository checks still matter.

Together, the measures explain the shift in the keynote: developers increasingly delegate complete tasks, then evaluate the result. That puts more emphasis on useful task context, review capacity and clear ownership of what gets shipped.
